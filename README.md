# Интерактивы для TikTok LIVE

Первая игра: **Монетный двор**. Подарок превращается в монету с аватаркой зрителя, монета падает в сундук.

## Запуск на планшете (Termux)

Один раз (установка и создание команды `coin`):

```sh
pkg install -y nodejs git
git clone https://github.com/c137mp3-cyber/Interactive- ~/interactive
cd ~/interactive && npm install && sh setup-coin.sh
```

Дальше перед каждым эфиром достаточно написать в Termux:

```sh
coin
```

Команда сама скачает свежую версию с GitHub, поставит недостающее, запустит мост на ник `c137mp3` и перезапустит его, если он упадёт. Другой ник: `coin ник`. Останавливается по Ctrl+C.

Если команды `coin` ещё нет, но проект уже стоит: `cd ~/interactive && git pull && sh setup-coin.sh`.

Откройте в Chrome: `http://localhost:8080`. Эфир должен уже идти, иначе мост будет переподключаться каждые 10 секунд.

- Красная точка в углу экрана: нет связи с эфиром.
- Тест с ботами на планшете: `http://localhost:8080/?test=1`. На экране будет метка TEST.
- GitHub Pages всегда открывает тестовый режим с ботами и не подключается к эфиру.

## Какой подарок даёт какую монету

| Цена подарка | Монета |
|---|---|
| от 1 | бронза |
| от 5 | серебро |
| от 20 | золото |
| от 30 | рубин |
| от 199 | бриллиант (200 монет в сундук) |

Игра занимает середину экрана (между шапкой и чатом TikTok). Границы зоны: `SAFE` в `games/mint/game.js`.

Цены и цели сундука меняются в начале `games/mint/game.js`: `TIERS` и `GOALS`.

Своя графика: см. `games/mint/ASSETS.md`.

## Новая игра

Папка `games/имя/` с подключением `core/live.js`. Мост и связь с эфиром общие.

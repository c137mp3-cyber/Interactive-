# Звуки Монетного двора

Положите mp3 с этим именем в эту папку и впишите имя в `SOUND_FILES` в начале `game.js`. Чего нет, синтезируется кодом.

| Файл | Когда звучит | Длина |
|---|---|---|
| `clank.mp3` | удар пресса по монете | ~1 с |
| `whoosh.mp3` | пресс опускается | ~0.5 с |
| `clink.mp3` | одна монета упала в кучу | ~0.4 с |
| `pour.mp3` | много монет сыплется в сундук | ~2 с |
| `reveal.mp3` | показ бронзы, серебра, золота | ~1.5 с |
| `reveal_big.mp3` | показ рубина и бриллианта | ~2.5 с |
| `build.mp3` | сундук трясётся перед взрывом | ~1.5 с |
| `win.mp3` | сундук взрывается | ~3 с |
| `king.mp3` | подарок от короля сундука | ~2 с |
| `rope.mp3` | монета повисла на цепочке | ~0.5 с |
| `belt_loop.mp3` | лента едет (петля) | 4–6 с |
| `amb_forge.mp3` | фон кузницы (петля) | 20–30 с |

Фоновая музыка: `music1.mp3`, `music2.mp3`, `music3.mp3` играют по кругу (список `MUSIC` в `game.js`, громкость `MUSIC_VOL`). Во время взрыва сундука и показа рубина, бриллианта или короля музыка притихает.

Уже есть: clank, build, belt_loop, amb_forge, music1–3.
